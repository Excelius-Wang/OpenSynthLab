# OpenSynthLab

**面向大模型的端到端数据合成框架。**

内置合成配方，支持自定义流程与质量验证。

[English](README.md) · [路线图](ROADMAP.md) · [贡献指南](CONTRIBUTING.md)

> **当前状态：项目初始化。** 仓库目前只有项目定位和路线图，尚无可运行的框架，也未发布 Python 包。下文描述的是计划建设的能力。

## 我们想解决什么问题

构建训练数据需要的不只是调用模型生成内容。用户还需要准备输入、组合方法、验证结果、筛选样本，并导出可用于训练的数据。

OpenSynthLab 希望把这些步骤串成完整流程。用户可以选择内置配方，配置模型、数据和参数后运行；也可以替换某个步骤，接入自己的合成方法、验证规则或工具环境。

```text
原始数据 / 任务定义
        ↓
内置配方 / 自定义流程
        ↓
数据生成 / 环境执行
        ↓
验证 → 评分 → 去重 → 筛选
        ↓
训练数据 + 来源记录 + 运行报告
```

## 计划覆盖的数据类型

| 类型 | 计划支持的场景 |
| --- | --- |
| 指令与对话 | 基于材料生成问答、扩展指令、多轮对话 |
| 推理数据 | 构建问题、生成解答、验证答案 |
| 偏好数据 | 生成候选回答、比较回答、评价质量 |
| Agent 轨迹 | 生成任务、执行工具与环境交互、验证任务结果 |
| 多模态数据 | 图文及其他多模态合成流程 |

## 设计原则

- 从生成到导出，提供可以复现的完整流程。
- 内置配方提供默认方案，模型、步骤和质量标准允许用户调整。
- 保留验证结果和数据来源，生成成功不等于质量合格。
- 区分模拟轨迹和实际执行得到的轨迹，记录工具返回和环境反馈。
- 为每种方法说明参考来源、适用条件、输入输出和限制。
